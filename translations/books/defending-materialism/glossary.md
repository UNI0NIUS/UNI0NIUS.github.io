# 《捍卫唯物主义》主要术语

同一英文词在不同学科中的含义可能不同，下表记录本版采用的主要译法，不代替语境判断。

|---|---|---|

| mechanical materialism | 机械唯物主义 | 与历史唯物主义、辩证唯物主义区分 |
| mechanist materialism | 机械论唯物主义 | 保留作者讨论机械论的语境 |
| dialectical materialism | 辩证唯物主义 | Diamat在需要时说明为苏联式辩证唯物主义 |
| historical materialism | 历史唯物主义 | |
