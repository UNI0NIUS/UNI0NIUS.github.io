# 术语表

本表记录本校对版的主要译法。具体语境可能需要不同表达；不把一般词义强行统一为术语。

| English | 中文 | 说明 |
| --- | --- | --- |
| materialism | 唯物主义 | 与 idealism 区分 |
| idealism | 唯心主义 | 哲学语境不译“理想主义” |
| dialectics | 辩证法 | 保留作者对不同历史形态的区分 |
| understanding / Verstand | 知性 | 康德、黑格尔语境 |
| reason / Vernunft | 理性 | 与知性区分 |
| a priori | 先天 | 不与 transcendental 混同 |
| transcendental | 先验 | 具体译法依语境 |
| thing-in-itself | 物自体 | 亦涉及事物本身的一般用法 |
| thing-for-us | 为我之物 | 与物自体相对 |
| in itself | 自在 | 哲学术语用法 |
| for itself | 自为 | 哲学术语用法 |
| in and for itself | 自在自为 | 不省略“自在” |
| appearance / essence | 现象／本质 | appearance 在一般语境亦译表象、外表 |
| substance | 实体 | 具体语境另作辨析 |
| extension | 广延 | 笛卡尔、斯宾诺莎语境 |
| sense-data | 感觉材料 | 不混同认识形式 |
| quality / quantity | 质／量 | 质不是质量 |
| measure | 度 | 黑格尔范畴 |
| nodal line of measurement | 度的节点线 | 黑格尔语境 |
| Notion | 概念 | 黑格尔术语 |
| antinomy | 二律背反 | 英文底本个别处误写 antimony，英文保留 |
| alienation | 异化 | 不等同对象化 |
| species-life | 类生活 | 马克思语境 |
| practice | 实践 | 与纯粹观照活动区分 |
| sophists | 智者／诡辩家 | 根据古代学派或贬义用法区分 |
| Shorter Logic | 《小逻辑》 | 不沿用旧译《简明逻辑》 |
| A Discourse on Method | 《谈谈方法》 | 统一正文与原注书名 |
| My Past and Thoughts | 《往事与随想》 | 赫尔岑著作 |
| MECW | 《马克思恩格斯全集》英文版 | 卷页信息依英文底本，不冒充中文版页码 |
| MESC | 《马克思恩格斯通信选集》英文版 | 卷页信息依英文底本 |
| LCW | 《列宁全集》英文版 | 卷页信息依英文底本 |
